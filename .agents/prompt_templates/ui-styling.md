# UI Styling Prompt Templates

Prompts to generate Tailwind tokens, color palettes, and component styles.

## Tailwind Palette

Prompt:

"Generate a Tailwind color palette for THEMANH SALON: primary (warm-amber), accent (muted purple), background (soft off-white). Output a `theme.extend.colors` snippet and recommended CSS variables."

## Component Tokens

Prompt:

"Create a set of design tokens (spacing, radii, elevation) suitable for a salon admin dashboard. Output tokens as CSS variables and a Tailwind `extend` snippet."
